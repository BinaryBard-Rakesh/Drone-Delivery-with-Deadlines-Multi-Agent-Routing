# Benchmark files

The workbooks contain source-destination path-length comparisons for PRS and A* across five map configurations:

- Berlin 256 x 256
- Berlin 1024 x 1024
- Boston 1024 x 1024
- London 1024 x 1024
- Milan 1024 x 1024

The 100-iteration workbook contains 100 runs per configuration. The 1,000-run workbook contains 1,000 runs per configuration. The files preserve the supplied data and formulas; interpret the results alongside the methods and limitations in [the project report](../docs/project-report.pdf).
